Darwin Core 匯出

下載一份符合 Darwin Core 標準的標本紀錄（CSV，打包為 ZIP）， 可供日後發布至 GBIF／TBIA。僅包含「公開」資料——這是對外的標準化子集。

欄位對應 Darwin Core（occurrenceID、catalogNumber、scientificName、eventDate…）。
occurrenceID 採全球唯一 UUID（urn:uuid 形式）；institutionCode 為 LYM。
保育類物種之精確經緯度一律留空，並以 informationWithheld 標示；仍保留縣市層級地點。
ZIP 內另附「授權與來源說明.txt」。

⬇ 下載 Darwin Core 匯出（.zip）

此匯出僅含公開資料。若需含未公開（草稿／待審）資料，請於後台「標本」清單勾選後， 使用批次動作「匯出為 Darwin Core CSV（含未公開資料）」（需公開權限）。
此功能與館內備份用的「全欄位匯出」為兩個獨立功能。
