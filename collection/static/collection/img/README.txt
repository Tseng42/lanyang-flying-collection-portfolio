首頁 hero 特展主視覺圖版位
==========================

把特展主視覺圖片放到這個資料夾，命名為：

    hero.jpg

放好後（正式模式下）執行一次收集靜態檔，即會顯示於首頁 hero 背景：

    python manage.py collectstatic --noinput

建議規格：
- 橫幅大圖，寬度 ≥ 1920px，橫向構圖（人物/主體避免貼齊上下邊）。
- 檔案格式 jpg（也可改用 png/webp，但需同步調整 home.html 內的檔名）。
- 圖片上方會疊一層半透明深藍罩以確保白色標題文字清楚，
  故偏亮或偏暗的圖都可用。

未放圖時：hero 會自動降級為深藍漸層底色（不會破圖）。
